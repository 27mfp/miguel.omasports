TL;DR: Confirmed audit bugs fixed, ESPN requests cached, fixture navigation improved, and the full local verification run passed. The implementation was committed as 172965c; release metadata and documentation are being prepared for the 1.5.0 PR.

## Implemented

- Cancel queued notifications when disabling via UI/IPC or switching sports; recheck enablement before dispatch.
- Normalize ESPN postponed/canceled states before generic final state; guard null competitors and malformed period scores; display provider cancellation reasons without fake scores.
- Resolve live-row and spotlight data from a fresh ID map independently of retained repeater identity, so inning/period-only changes reach the UI.
- Exclude overdue kickoffs and reconsider the next candidate when the clock passes it.
- Prioritize today's ESPN slate; cache today/live days for 15 seconds and surrounding days/standings for five minutes; retain bounded current-window caches across sports and retry failed days without refetching successful ones.
- Serial-gate deferred completion, suppress duplicate round completion, and guard repeated starts on a running worker.
- Add accessible section/expansion actions and selected focus outlines. Keyboard fixture indices now follow filtered, actually visible rows.
- Wrap spotlight team names across two lines.
- Avoid redundant state reads on open and ignore own-write state echoes that could restore an obsolete route.
- Restore mock-mode display state without resurrecting canceled loading flags or notification queues.
- Correct sport-specific mock enrichment, standings group names and inning/period data. Freeze visual-test time.
- Verify source revision, route and sport before screenshot capture. Correct crop tracing to avoid wallpaper below short panels.
- Consolidate install guidance and document the optional offscreen runtime check.

The offscreen process test is isolated and opens no windows. ## Remaining scope

- Hosted CI includes the new controller regressions, but a full Quickshell runtime/visual CI environment was not provisioned. The offscreen runtime gate is available locally through --runtime.
- Keyboard wiring is covered by source checks and IPC interactions, not a comprehensive assistive-technology or physical-keyboard test.
- Additional scale coverage is targeted to MLB fixtures. Full light/dark-theme matrices were not run because the host shares global theme state with the user's desktop; changing it for testing would affect the session.
- MLB/NHL playoff seed semantics and ESPN extreme-timezone interpretation remain investigations, not confirmed bugs warranting speculative changes.
- Compact spotlight details, three-result previews with expansion, and contextual keyboard hints are now implemented. Expanded results show all loaded results within the existing ten-result model cap.
- Expanded MLB, F1 and football captures have dedicated visual baselines.
